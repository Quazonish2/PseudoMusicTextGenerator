# Pseudo Music Text Generator

Create playful, rhyme-based pseudo lyrics from invented English-like words. The generator runs entirely in your browser and does not use AI.

## Run it

Open `index.html` in a web browser, choose the number of verses, lines per section, outro lines, and syllables per line, then select **Generate lyrics**.

The generated song repeats the chorus after each verse and ends with an outro. Use **Copy lyrics** to copy the result.
